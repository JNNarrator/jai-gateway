UI/UX优化建议，重点放在**降低认知负荷、减少误操作、提升可读性与可发现性**上。

------

### **1. 网关（首页）**

**目标**：让用户一眼看清“是否在运行”和“怎么接入”。

- **网关状态卡片**
  - [x] **视觉层级**：把 IP:端口 和“运行中/已停止”用更大的字号或标签区分，当前两者并列容易弱化。
  - [x] **状态指示**：保留绿色圆点，但增加一个“运行中”的小标签或色条，远看也能判断。
  - [x] **端口顺延说明**：把“停机会自动顺延”的信息改成小字提示（tooltip 或 help icon），避免主文案太长。
  - [x] **操作按钮**：“启动/停止”建议根据当前状态只显示一个，或高亮当前可用按钮，禁用不可用按钮，减少误点。
- **客户端接入卡片**
  - [x] **Base URL / API Key**：输入框右侧放“复制”图标，比“显示全文”更常用；“显示/隐藏”放在“复制”旁边，图标化。
  - [x] **轮换按钮**：文案改为“轮换密钥”，并增加一个二次确认弹窗，说明“旧密钥将失效”。
  - [x] **代码片段**：增加“复制”按钮；如果 SDK 可选，提供下拉切换（DeepSeek / OpenAI / curl），当前只展示一种写法。
  - [x] **可访问性**：代码区域使用等宽字体和暗色背景对比度优化。
- **配置迁移卡片**
  - [x] **导出按钮**：文案改为“导出配置（无敏感字段）”，并在下方小字补充“密钥不会包含在内”。
  - [x] **导入说明**：把“导入功能在 M7 提供”改为版本号或“当前版本不支持”，避免“M7”对部分用户不可理解。
  - [ ] **操作反馈**：导出成功后出现一个短暂的 toast 提示“已导出”，并在旁边提供“打开所在目录”（如果平台支持）。

### **2. 同步**

**目标**：导入导出与 WebDAV 同步都强调“安全”和“后果”。

- **导入导出 JSON**
  - [x] **前置警告**：在文本框上方加一个 info banner：“导出不包含 API Key，导入后需在「供应商」页补录”。
  - [ ] **文本框**：增加“粘贴”按钮（读取剪贴板），方便移动设备或无键盘场景；高度可拖拽或自动展开。
  - [ ] **导入按钮**：点击后弹出确认框，列出即将变更的条目数量，并提示“当前本地配置将被覆盖/合并”。
  - [x] **导出入口**：提示中写“导出仍在「网关」页”，可加一个可点击的跳转链接，减少查找成本。
- **WebDAV 同步**
  - [ ] **字段校验**：根地址必填且自动补全尾部斜杠；用户名/密码在保存后可选“记住”或“仅本次”。
  - [ ] **密码字段**：右侧增加“显示/隐藏”和“测试连接”按钮，减少盲目推送/拉取。
  - [ ] **操作按钮**：“推送/拉取”前增加“预览变更”步骤，显示将要覆盖的条目，避免误覆盖。
  - [ ] **状态提示**：操作后显示进度条和结果摘要（成功/失败/冲突条目）。

### **3. MCP Server 管理（列表页 & 添加页）**

**目标**：让添加流程更顺滑，列表页能一眼看到服务类型和健康状态。

- **列表页（还没有 MCP Server）**
  - [x] **空状态**：当前文案较抽象，建议改为：“还没有 MCP Server。点击上方按钮添加一个 stdio/SSE/HTTP 类型的服务。”
  - [ ] **添加按钮**：保持右置，但颜色加深或增加 hover 动效，提升可发现性。
- **添加/编辑页**
  - [x] **表单布局**：两列布局在窄屏会挤压，建议改为单列自适应；“名称”和“类型”同行可以保留，但确保 label 与输入框对齐。
  - [x] **类型选择**：选中后下方动态展示对应类型的必填项和示例，例如 stdio 显示命令+参数，SSE 显示 URL，HTTP 显示 URL + Auth。
  - [x] **参数输入**：JSON 数组输入框增加语法高亮和实时校验，错误时显示具体哪个索引有误。
  - [x] **操作按钮**：“创建/取消”与“测试连接”并列，先测试再创建，减少配置错误。
  - [x] **帮助提示**：每个字段下方加一行小字示例，比如参数：`["-y", "@modelcontextprotocol/server-filesystem"]`。

### **4. 技能（Skill）管理**

**目标**：让“技能”概念更直观，导入添加更快捷。

- **空状态**
  - [x] **文案优化**：“还没有技能。技能是一组可复用的指令/提示词/工作流定义，点击添加或导入 ZIP 开始。”
  - [x] **引导示例**：提供一个“示例技能”按钮，点击后自动填充一个模板，降低上手门槛。
- **操作按钮**

  - [x] **添加技能**：点击后弹出侧滑面板或模态框，内嵌表单，避免跳转页面打断流程。
- **列表页（待补充）**
  - [ ] **预期字段**：名称、类型、启用状态、最后修改时间、操作（编辑/删除/测试）。
  - [x] **批量操作**：支持批量启用/禁用/删除，提升管理效率。

### **5. 供应商**

**目标**：让添加供应商更防呆，列表页更可读。

- **添加供应商表单**
  - [x] **协议族联动**：选择协议族后，Base URL 的 placeholder 和下方提示自动切换，例如 OpenAI 提示填 `/v1`，Gemini 提示填主机根。
  - [x] **API Key**：增加“从环境变量导入”或“从密钥管理器读取”选项，减少手动粘贴错误。
  - [x] **路由优先级**：增加一个滑块或数字输入，旁边显示“数字越小越优先”，避免用户误解“100”是高还是低。
  - [x] **追加请求头**：提供一个结构化编辑器（key-value 对），比纯 JSON 输入更不容易出错。
  - [x] **测试连接**：点击后显示 loading 状态，成功/失败都有明确提示，失败时给出可能原因（网络、Key、URL）。
- **列表页**
  - [x] **信息分层**：名称、协议、URL、优先级、状态（最近成功/失败）分三行或两列展示，当前挤在一行太长。
  - [x] **操作按钮**：测试/拉取模型/编辑/删除，增加 hover 显示全称，避免图标太小误触。
  - [x] **状态标签**：“最近成功”用绿色标签，“失败”用红色，中间状态用灰色，一眼可辨。

### **6. 模型**

**目标**：模型配置表更易扫读，批量操作更高效。

- **模型默认值表**
  - [ ] **列宽优化**：模型名列宽加大，上下文和最大输出列宽缩小，启用列居中。
  - [x] **输入控件**：上下文/最大输出用数字输入框，带上下箭头，步长可设（如 1024）。
  - [x] **启用开关**：用 toggle switch 代替 checkbox，视觉更现代，操作更顺手。
  - [x] **保存反馈**：每行保存后显示“已保存”绿勾，3秒后消失，避免用户不确定是否生效。
  - [x] **批量操作**：顶部增加“全部启用/禁用”、“批量保存”按钮，减少逐行操作。
- **搜索/筛选**
  - [x] **增加搜索框**：按模型名、协议族、供应商筛选，模型多时快速定位。
  - [x] **排序**：点击表头可按名称、上下文、启用状态排序。

**目标**：让日志更易读、可追溯、可导出。

  - [x] **分页/虚拟滚动**：日志多时避免一次性加载，增加分页或虚拟滚动，提升性能。
- **操作区**
  - [x] **自动刷新**：保留开关，但增加刷新间隔设置（5s/10s/30s）。
  - [x] **导出按钮**：增加“导出 CSV/JSON”按钮，方便排查问题。
  - [x] **筛选器**：按时间范围、状态码、模型名筛选，快速定位问题请求。
- **底部说明**

### **8. 设置**

**目标**：让配置项更安全、更易理解，避免误改。

- **网关端口**

  - [x] **保存反馈**：保存后显示“端口已更新，网关将重启”并倒计时，避免用户以为没生效。
  - [ ] **冲突提示**：如果端口被占用，保存前就提示“端口1314已被占用，将自动顺延至1315”，并让用户确认。

- **请求日志**

  - [x] **开关状态**：“记录/关闭”用 toggle switch，当前按钮样式像普通按钮，不够直观。
  - [ ] **保留策略**：30天/5万行 可点击编辑，弹出模态框修改，避免直接暴露复杂配置。

- **浏览器跨域白名单（CORS）**

  - [ ] **输入框**：每行一个域名，增加“添加”按钮，支持粘贴多行自动分行。

  - [x] 预置示例

    ：下方放一行灰色示例：“

    https://chat.example.com”

    ，点击可填入。

  - [x] **安全提示**：加一个 warning banner：“通配符 * 会放行所有来源，生产环境不建议使用。”

- **关于密钥存储**

  - [x] **可视化**：用图标+文字代替纯文本，例如文件图标+“文件降级 (0600)”，钥匙图标+“密钥管理器”。
  - [x] **操作链接**：“见设置页”可点击跳转到对应配置项，减少查找。
  - [x] **删除警告**：删除供应商时弹出确认框，说明“同时清除对应凭据，不可恢复”。

### **全局通用建议**

1. **一致性**
   - 所有“保存/创建/导入”按钮颜色统一，主操作橙色，次要操作灰色。
   - 所有输入框高度、圆角、间距保持一致，当前部分页面输入框高度略有差异。
2. **反馈机制**
   - 所有操作（保存、删除、导入、导出）都有 toast 或 snackbar 提示，成功/失败/进行中三种状态。
   - 加载状态用骨架屏或 spinner，避免空白页让用户以为卡住。
3. **响应式**
   - 窄屏（<1024px）时，表单改为单列，表格可横向滚动或卡片化展示。
   - 移动端适配：按钮大小至少 44px，方便触控。
4. **可访问性**
   - 所有图标按钮都有 aria-label 或 tooltip。
   - 颜色对比度符合 WCAG 2.1 AA 标准，当前暗色主题部分文字对比度偏低。
   - 支持键盘导航，Tab 键可遍历所有表单元素，Enter 键提交。
5. **帮助系统**
   - 每个复杂配置项旁加一个“?”图标，hover 显示详细说明和示例。
   - 右上角加一个“文档”链接，跳转到在线帮助或 GitHub Wiki。
