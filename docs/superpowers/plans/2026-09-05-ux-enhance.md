# 下一迭代：UX 体验增强（Desk UX）

> 提案日期：2026-09-05 · 前置：v0.1.7（已发布，CI 出包完成）
>
> 一句话目标：把「网关操作员」的日常动线——查日志、找配置、看状态、上手首次使用——
> 从"能用"提升到"顺手"。纯体验迭代，不动网关转发核心，dsh 链路零风险。

## 迭代范围（4 项任务 + 1 可选）

### T1 日志页体验升级（诊断主路径）⭐推荐
- **行点击 → 详情侧栏**：状态码、耗时、输入/输出 token、流式标记、错误信息、模型/供应商、
  时间线化展示；「复制为 cURL」按钮——用行内数据拼出可复现命令
  （`curl <网关>/v1/chat/completions -H "Authorization: Bearer <密钥>" -d '{"model":"…","messages":[{"role":"user","content":"…"}]}'`，
  请求体为占位模板——日志按隐私基线只存元数据，模板注明「粘贴真实请求体即可复现」）。
- **供应商筛选下拉**（LogRowView 已有 `providerId`，纯前端，无后端改动）。
- 附件：列排序（耗时/状态）、错误列红显（已有 statusClass，可顺带）。

### T2 Ctrl+K 命令面板（全局检索 + 快捷操作）
- 全屏浅层遮罩 + 输入框（fuzzy 匹配）：
  - **跳转**：9 个页面 tab
  - **对象搜索**：供应商（跳 ProviderPage 并定位）、模型、网关密钥名
  - **快捷操作**：复制网关端点、生成新密钥、WebDAV 立即推送、测试全部供应商连接
- 纯前端组件（`CommandPalette`）+ nav/现有 API 接线；ESC 关闭、↑↓ 选择、Enter 执行。

### T3 启动健康自检横幅（网关页）
- 新 IPC `health_summary`：返回最近一轮健康检查的 `{checked_at_ms, down: [{provider, err}]}`。
- 网关页顶部横幅：`上次健康检查 HH:mm · 2 个供应商当前不可用`，点「查看」跳供应商页并展开；
  全部正常时显示绿色小徽章（不打扰）。健康检查循环（10min/轮，已存在）顺带把最新摘要写入内存槽。

### T4 首次使用向导（空库三步引导）
- 首次启动且无供应商/无网关密钥时，在网关页顶部显示可关闭的引导卡：
  1. **生成网关密钥**（一键调用现有 IPC，复制端点）
  2. **添加第一个供应商**（跳供应商页，预填 OpenAI 兼容模板）
  3. **测试连通**（一键探测全部已启用供应商）
- 完成任一步骤自动推进；「不再提示」写 meta（`ui_first_run_done`）。纯前端 + 1 个 meta IPC。

### T5（可选）WebDAV 冲突可视 diff
- 把 T3 差异预警（推送前）从"计数提示"升级为**可视 diff 抽屉**：展开列出
  远端独有供应商/模型（将被覆盖丢失）与本地独有条目，逐条确认或勾选后仍推送。
- 延续同步可靠性主题；若本期不做可留作 sync-v3。

## 验收标准

- T1：点击日志行 → 详情侧栏 + cURL 复制（无头验证交互）；供应商筛选生效。
- T2：Ctrl+K 唤起，跳转/搜索/快捷操作各验证一条。
- T3：健康摘要 IPC 返回结构正确；横幅在 down>0 时出现、全绿时不打扰。
- T4：空库显示引导、逐步推进、关闭后不再出现（meta 落库）。
- 全量门禁：fmt / clippy `-D warnings` / `cargo test --workspace` / tsc + vite build；
  无头 Chrome 逐页断言 + 截图留档；**dsh/zcode 转发链路零改动**。

## 风险与决策点（开工前拍板）

1. **T1 cURL 请求体**：日志只存元数据 → 模板占位（默认）。若希望存请求体（隐私升级开关），
   需新 meta `log_store_body`（默认关）+ 落库列变更，量级 +0.5d，默认不做。
2. **T2 模糊匹配**：前端自带简单 fuzzy（不引依赖）vs 引入 `fuse.js`（轻量）。默认不引依赖。
3. **T3 健康摘要来源**：复用现有健康循环内存槽（推荐）vs 启动时立即跑一轮探测（会触发真实上游请求）。默认复用。
4. **T5**：是否并入本期由你定。
